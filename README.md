# Toán tư duy – ứng dụng Android (offline)

Tải file `toan-tu-duy-offline.apk` ở mục **Releases** rồi cài lên máy tính bảng / điện thoại Android 7.0 trở lên
(cho phép "cài ứng dụng từ nguồn không xác định" khi được hỏi).

Ứng dụng chạy **hoàn toàn offline**: không cần Internet hay máy chủ. Gồm 12 chủ đề, 251 bài học (video) và 251 bài kiểm tra.
Tiến độ và điểm số lưu ngay trên thiết bị. Dung lượng khoảng 40 MB.
