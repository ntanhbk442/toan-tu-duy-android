# Toán tư duy – ứng dụng Android

Tải file `toan-tu-duy.apk` ở mục **Releases** rồi cài lên máy tính bảng / điện thoại Android
(cho phép "cài ứng dụng từ nguồn không xác định" khi được hỏi).

Lưu ý: bản này là bản thử nghiệm, chỉ kết nối được khi máy chủ của ứng dụng đang chạy trong cùng mạng Wi-Fi.
